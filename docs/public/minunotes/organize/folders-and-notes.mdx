Folders provide the main hierarchy in MinuNotes. Notes hold the actual content, while subfolders let a larger area grow without flattening everything into one list.

## Choose a simple structure

Start with a few durable areas rather than a folder for every topic:

```txt
Projects/
Research/
Meetings/
Archive/
```

Add subfolders only when a folder becomes difficult to scan.

## Create content

Select a folder, then create a note or subfolder from its available actions. A note belongs to one folder at a time and can be moved later.

Use clear note titles. Titles power navigation, search results, and wikilink suggestions.

## Move and rename

Use the note or folder actions to rename or move content. Moving a folder moves its descendants with it.

Before reorganizing a shared folder, consider how the change affects collaborators who rely on its hierarchy.

## Board columns

Switch a folder to **Board** for a read-only view grouped by a Select property. Owners can open **Board settings**, choose the **Columns** grouping property, check **Visible columns** and optional **Card properties**, then **Save board**. Cancel applies nothing; these settings never edit notes or their property values.

- **Unclassified** includes unset, archived, unknown, or invalid grouping values—not just unset values. A hidden valid status never moves into Unclassified.
- Uncheck columns to hide them for everyone viewing the Board, including public-link recipients. Hiding columns does **not** restrict List, search, or direct-note access.
- Uncheck everything, including Unclassified, to show **No columns selected**. The Board remains enabled; check a column and save to show cards again.

Default settings include all active options plus Unclassified and automatically include new options. Saving any visibility checkbox change creates an explicit selection: options added later stay unchecked, even if every current option is checked. There is no reset control.

Select definitions determine column names and order. Owners manage those definitions in folder Properties settings, not by creating or dragging Board columns.

## Folders versus tags and links

- **Folders** answer “Where does this belong?”
- **Tags** answer “What theme or status does this have?”
- **Wikilinks** answer “What other idea is this connected to?”

Using all three lightly is usually more useful than building a very deep folder tree.
