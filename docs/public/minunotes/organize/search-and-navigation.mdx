MinuNotes combines folder navigation with workspace-wide search so you can use structure when it helps and search when it is faster.

## Search quickly

Press `Cmd/Ctrl+K` to open search. Search by words from a note title or content, or by a folder name.

Choose a result to open it directly. Search remains useful even when you do not remember where a note lives.

## Filter notes in a folder

In a folder's List or Board view, open **Filter** and **Add property**. For a Select property, check values and/or **Not set**. For example, Backlog plus Not set matches either; conditions on different properties must all match.

Not set means missing, null, or blank—not archived, unknown, or invalid values. Choose **Apply** to use the draft or **Cancel** to discard it. Filters do not change note values, access, or the owner's Board settings.

## Navigate folders

Use the sidebar to open folders and expand subfolders. The breadcrumb above the main content shows the current location and provides a quick path back to a parent.

On a smaller screen, open the navigation menu to reach the same workspace destinations.

## Use descriptive titles

Short, specific titles improve search results and wikilink suggestions. Prefer `OAuth rollout checklist` over `Checklist` when multiple notes could share a generic name.

## Connect instead of nesting deeply

If a note belongs conceptually to several areas, keep it in one clear folder and use tags or wikilinks for the other relationships.
