Discussion concerns the whole note. Anchored Review concerns specific wording. Both use the same note-owned threads and plain-text messages; the note body remains the current source of truth.

## Discuss the note

Discussion appears below the body of an active Markdown note. Choose **Discussion** in the header to jump to the section and focus its composer, then enter a comment and choose **Post**. No text selection or content-edit access is needed, and posting does not force-save unrelated body edits.

Opening the same note from a list or Board reaches the same discussion. General comments remain attached after body edits and renames; they have no text anchor and never become detached.

## Review specific text

Select text or use a line comment action to create an anchored Review thread. Open **Review** to see these threads in the existing responsive drawer. Selecting an anchored thread focuses its source; general discussion does not create editor highlights or gutter markers.

MinuNotes maps Review anchors as the note changes. If the original text can no longer be mapped safely, the thread appears detached rather than attaching to unrelated content.

## Reply, react and resolve

Select a thread to reply. Add or remove your own emoji reactions, edit your own messages, and resolve or reopen threads within your permissions. Resolving discussion does not change workflow properties or Board placement.

Deleting a reply removes that message; deleting the root message or discussion removes the entire thread and its replies. Note owners can moderate deletion; message editing remains author-only.

## Permission required

Owners, Editors and Commenters can discuss notes without broadening their existing permissions. Viewers and public-share visitors do not gain comment access. Connected agents need explicit Comment plus read access and remain subject to their authorization scope and author-only mutation rules. Comments are not available for templates, canvases or Trash.
