MinuNotes supports signed-in collaboration and anonymous public links. Choose the narrowest option that fits the work.

## Invite a collaborator

Open a note or folder's sharing controls, enter the person's email address, and choose a role:

- **Viewer** can read.
- **Commenter** can read and participate in Review comments.
- **Editor** can change content within the allowed collaboration boundary.

Invited collaborators sign in with the invited email address.

## Share a folder

A folder role applies to its existing and future descendants. Folder sharing is useful for an ongoing project where collaborators need a consistent workspace.

Share one note instead when the person only needs a specific document.

## Create a public link

Public links provide anonymous, read-only access. Anyone with the link can open the shared material, so do not use one for private or audience-restricted information.

Folders can be viewed as a list or a read-only board using the same public link and access settings. Copying the link from board view opens it as a board, including its configured card properties. Recipients can switch views; sharing still covers the folder and its descendants, not just the visible cards.

Turn public access off when the link is no longer needed. This disables both list and board access.

## Ownership boundaries

Shared content remains in its owner's workspace. Some owner-only actions—such as managing sharing, public links, restore, and permanent deletion—are intentionally unavailable to collaborators.

## Review access regularly

Remove invitations and public links that are no longer required. For connected agents, review integration scope separately from human collaboration access.
